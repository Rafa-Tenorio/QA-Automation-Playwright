# QA-Automation-Playwright

Repositório de automação de testes E2E utilizando **Playwright** e **TypeScript**.

## 🧪 Testes Implementados

* **Google Home:** Validação da página inicial.
* **Get Started:** Teste de navegação na documentação.
* **Playwright Install:** Validação de instalação.

## 🛠 Tecnologias
* **Playwright**
* **TypeScript**
* **VS Code**

## 🚀 Guia Rápido
Para rodar o projeto, clone o repositório, entre na pasta, instale as dependências com `npm install` e execute `npx playwright test`.
